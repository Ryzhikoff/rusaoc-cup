# Country flag images

Self-hosted 4:3 SVG flags from [flag-icons](https://github.com/lipis/flag-icons), version 7.6.0.

Pinned source: https://github.com/lipis/flag-icons/tree/ac7e0eb3259eb62aa6100c435607e2fe03896a97/flags/4x3

Contains the 249 ISO country codes supported by `scripts/liquipedia.py`. Flags are served locally without external CDN requests or emoji-font dependencies. The original SVG files are unmodified; see [LICENSE](LICENSE).
